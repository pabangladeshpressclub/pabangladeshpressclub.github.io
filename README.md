# Pennsylvania Bangladesh Press Club — Website

এটি PBPC-এর অফিসিয়াল ওয়েবসাইট। GitHub Pages-এ বিনামূল্যে চলে।

## কোন ফাইলে কী আছে

| ফাইল / ফোল্ডার | কী আছে |
|---|---|
| `data/content.js` | **সব তথ্য এখানে** — নেতৃবৃন্দ, ফি, অনুষ্ঠান, সংবাদ, সদস্য, গ্যালারি, ইমেইল, সোশ্যাল লিংক |
| `assets/photos/leaders/` | নেতৃবৃন্দের ছবি |
| `assets/photos/members/` | সদস্যদের ছবি |
| `assets/photos/events/` | অনুষ্ঠানের ব্যানার/ছবি |
| `assets/photos/news/` | সংবাদের ছবি |
| `assets/photos/gallery/` | গ্যালারির ছবি (প্রতি অনুষ্ঠানের জন্য আলাদা ফোল্ডার) |
| `assets/docs/` | গঠনতন্ত্র বা অন্যান্য PDF |
| `*.html` | পাতাগুলো (সাধারণত বদলানোর দরকার নেই) |

## কীভাবে আপডেট করবেন (GitHub ওয়েবসাইট থেকেই)

### নতুন সংবাদ দেওয়া
1. GitHub-এ `data/content.js` খুলুন → পেনসিল (✏️) চিহ্নে ক্লিক করুন।
2. `news: [` অংশে একটি এন্ট্রি কপি করে নিচে পেস্ট করুন, তারপর লেখা বদলান।
3. প্রতিটি এন্ট্রির শেষে কমা `,` আছে কি না দেখুন।
4. নিচে **Commit changes** চাপুন। ১–২ মিনিট পর ওয়েবসাইটে দেখা যাবে।

### ছবি আপলোড করা
1. যে ফোল্ডারে রাখতে চান (যেমন `assets/photos/leaders`) সেটি খুলুন।
2. **Add file → Upload files** → ছবি টেনে আনুন → **Commit changes**।
3. `content.js`-এ ঐ ব্যক্তির `photo: ""` এর মধ্যে ফাইলের নাম লিখুন, যেমন `photo: "president.jpg"`।

টিপস: ফাইলের নামে স্পেস বা বাংলা অক্ষর না দেওয়াই ভালো (`agm-2026-01.jpg` এরকম)। ছবি ১–২ MB-এর কম রাখুন।

### গ্যালারিতে ছবি যোগ
1. `assets/photos/gallery/` এর মধ্যে নতুন ফোল্ডার বানান: Add file → Create new file → নাম লিখুন `agm-2026/.gitkeep` → Commit।
2. ঐ ফোল্ডারে ছবি আপলোড করুন।
3. `content.js`-এর `gallery: [` অংশে উদাহরণের মতো একটি অ্যালবাম যোগ করুন।

### "Sample" ব্যাজ সরানো
নমুনা এন্ট্রিগুলোতে `draft: true` লেখা আছে। আসল তথ্য বসানোর পর ঐ লাইনটি মুছে দিন। সব আসল তথ্য দেওয়া হয়ে গেলে `showDrafts: true` কে `false` করে দিন।

## ফর্ম
- **সদস্যপদ আবেদন:** Google Form বানিয়ে লিংকটি `applicationFormUrl`-এ বসান।
- **যোগাযোগ ফর্ম:** https://formspree.io-তে ফ্রি অ্যাকাউন্ট খুলে ফর্মের লিংক `contactFormEndpoint`-এ বসান। না দিলে ফর্মটি দর্শকের ইমেইল অ্যাপ খুলে দেবে।

## যা এই ফ্রি ওয়েবসাইটে সম্ভব নয়
GitHub Pages শুধু স্থির (static) ওয়েবসাইট চালায়। তাই সদস্য লগইন, অনলাইন পেমেন্ট, অ্যাডমিন ড্যাশবোর্ড ও ডেটাবেস এখানে নেই। এগুলোর বদলে Google Form (আবেদন), Formspree (যোগাযোগ) এবং `content.js` (তথ্য হালনাগাদ) ব্যবহার করা হয়েছে। প্রেস আইডি যাচাই পাতা `credentials` তালিকা থেকে কাজ করে।
